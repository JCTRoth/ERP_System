== Overview

The frontend application is built with React 18 and TypeScript, using Vite as the build tool.

In addition to the ERP admin frontend (`apps/frontend`), this repository also contains a dedicated customer storefront (`apps/webshop`).

== Technology Stack

* **React 18** - UI library with concurrent features
* **TypeScript** - Type-safe JavaScript
* **Vite** - Next-generation build tool
* **TailwindCSS** - Utility-first CSS framework
* **Apollo Client** - GraphQL client
* **Zustand** - Lightweight state management
* **React Router** - Client-side routing
* **@dnd-kit** - Drag-and-drop functionality
* **Heroicons** - Icon library

=== Runtime and API Integration

* Dev URL: `http://localhost:5174`
* Vite proxy forwards `/graphql` to `process.env.GATEWAY_URL` or `http://localhost:4000`
* Apollo client sends `X-Company-Id` on each request (`VITE_COMPANY_ID` with demo fallback)
* Cart uses session-based guest flow via `cartBySession` and cart mutations

== Key Features

=== Authentication

The application uses JWT-based authentication with:
* Access token (short-lived)
* Refresh token (long-lived)
* Automatic token refresh
* Protected routes

[source,typescript]
----
// stores/authStore.ts
const useAuthStore = create<AuthState>()(
  persist(
    (set, get) => ({
      user: null,
      accessToken: null,
      refreshToken: null,
      isAuthenticated: false,
      // ...
    }),
    { name: 'erp-auth' }
  )
);
----

=== Internationalization

Multi-language support with dynamic loading:

[source,typescript]
----
// Using translations
const { t } = useI18n();
<h1>{t('dashboard.title')}</h1>

=== State Management

Zustand for lightweight, scalable state:

[source,typescript]
----
// Using stores
const user = useAuthStore((state) => state.user);
const sidebarOpen = useUIStore((state) => state.sidebarOpen);
----

== UI Builder

The visual UI builder allows creating custom pages:

* Drag-and-drop interface
* Component palette with categories
* Properties panel for customization
* Code export (React/JSON)
* Page management
* **Script Editor** — attach JavaScript to buttons with Monaco editor
* **Database Access** — scripts can read/write data from any ERP service via `ERP.query()` / `ERP.mutate()`
* **Access Control** — per-page and per-component visibility rules (roles, permissions, groups)

See link:scripting-guide.adoc[Scripting Guide] for detailed documentation on writing scripts with database access.
